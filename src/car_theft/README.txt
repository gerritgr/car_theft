src/car_theft/
==============

The main Python package for this project.

Modules
-------
__init__.py  - Package initialisation (version, public API).
main.py      - CLI entry point: loads data and prints summary statistics.

Extending the package
---------------------
Add new Python files here for data loading, feature engineering, model
definitions, evaluation utilities, etc.  Import them in notebooks with:

    from car_theft import <module>

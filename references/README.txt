references/
===========

Static reference material that supports the analysis but is not generated by
code.  Examples include:

- Data dictionaries and field descriptions for the NYC Vehicle Collisions
  dataset.
- Academic papers and reports cited in the project.
- External lookup tables (e.g. borough / ZIP-code mappings).
- Any licences or terms-of-use documents for third-party data.

Files in this directory should be checked into version control so that the
project is self-contained and reproducible.

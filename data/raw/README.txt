data/raw/
=========

Raw, immutable LAPD crime report CSV files. One file per year.

Contents
--------
rd_cnvy_crme_YYYY.csv  - LAPD vehicle-related crime records for year YYYY.
                         Files cover 2000-2022. These records are not public.

Important
---------
Do NOT modify any files in this directory. If you need to transform the data,
write the output to data/processed/ instead.

These CSV files are excluded from version control via .gitignore.

data/raw/
=========

Raw, immutable data downloaded directly from the source.

Contents
--------
vehicle_collisions.csv  - NYC Vehicle Collisions dataset downloaded from
                          https://www.kaggle.com/datasets/nypd/vehicle-collisions
                          (populated by running `python data/download_data.py`).

Important
---------
Do NOT modify any files in this directory.  If you need to transform the data,
write the output to data/processed/ instead.
